MuuTask
=======
バージョン v@VERSION@

Windows のタスクバーの中に、いま再生中の曲を表示するミニ プレーヤーです。
アルバム アート + 曲名 + アーティスト + 再生ボタンがタスクバーの空きスペースに
並びます。Python のインストールは要りません。


必要なもの
----------

* Windows 10 (64bit) 以降。Windows 11 で動作を確認しています。
* Windows のメディア コントロール (音量ポップアップに出るあれ) に対応した
  再生アプリ。Spotify、YouTube などのブラウザー再生、メディア プレーヤー、
  foobar2000、VLC、AIMP などが該当します。


使い方
------

1. この zip の中身を好きなフォルダーに展開します。
   (例: C:\Users\<ユーザー名>\Apps\MuuTask)
2. MuuTask.exe をダブルクリックします。
3. タスクバーの通知領域のとなりにバーが出ます。停止中は
   「再生中の音楽はありません」と表示されます。

初回起動時に「WindowsによってPCが保護されました」と出ることがあります。
コード署名をしていないためです。[詳細情報] → [実行] で起動できます。

終了するときは、バーかトレイ アイコンを右クリックして [終了] を選びます。


操作
----

タスクバーの再生ボタン        前の曲 / 再生・一時停止 / 次の曲
タスクバーの曲名をクリック    詳細パネルの開閉
タスクバーを右クリック        メニュー (表示位置・再生元・表示設定・終了)
トレイ アイコンを左クリック   詳細パネルの開閉
パネルの余白をドラッグ        位置を移動 (次回も同じ位置に出ます)
進捗バーをクリック            シーク
Esc                           パネルを閉じる


設定
----

右クリック メニューから変更できます。

* 表示位置        タスクバー内のどこに置くか (左端 / スタート ボタンの左 /
                  通知領域の左)
* 再生中のときだけ表示
* 詳細パネルを常に表示
* 再生元          複数のアプリが鳴っているときに追いかける対象

設定は MuuTask.exe と同じフォルダーの config.json に保存されます。
バーの幅 (bar_width)、通知領域との間隔 (bar_gap)、地色 (bar_bg) はこの
ファイルを直接編集して調整できます (編集後はアプリを再起動してください)。

書き込めない場所 (Program Files 直下など) に置くと設定を保存できません。
ドキュメントやユーザー フォルダーの下に置いてください。


自動起動
--------

エクスプローラーのアドレス バーに shell:startup と入力して開いたフォルダーへ、
MuuTask.exe への「ショートカット」を置いてください。次回のログオンから自動で
常駐します。

アプリ側に自動起動の設定を持たせていないのは、レジストリに何も書かないためです。
MuuTask.exe を移動したときは、リンクが切れるのでショートカットを作り直します。


アンインストール
----------------

1. 右クリック メニューの [終了] でアプリを終了します。
2. shell:startup にショートカットを置いた場合は、それを削除します。
3. 展開したフォルダーを削除します。設定 (config.json) も一緒に消えます。

以上です。レジストリにもシステム フォルダーにも何も書き込んでいないので、
ほかに消すものはありません。

(読み取りだけはレジストリを使っています。ダーク / ライトの別とアクセント
 カラーを取得する部分で、書き換えは一切しません)


制限
----

* スタート メニューを開いている間は、バーがタスクバーの後ろに隠れます。
  スタート メニューを閉じると自動的に (0.3 秒ほどで) 戻ります。
* 起動中のアプリが多くてタスクバーが埋まると、アプリのボタンと重なることが
  あります。その場合は config.json の bar_width を小さくしてください。
* 全画面のアプリ (ゲームや動画) が前面にあるときは、バーは自動的に隠れます。
* マルチ ディスプレイでは、メインのタスクバーにのみ表示されます。
* シークは再生アプリが対応している場合のみ有効です。
* ダーク / ライトとアクセント カラーは起動時に読み込みます。変更した場合は
  MuuTask を再起動してください。
